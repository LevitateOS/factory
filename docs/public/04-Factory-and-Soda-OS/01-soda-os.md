# Factory and Soda OS

Factory runs a software factory on one computer. Soda OS runs a company's shared factory. Both use the same interface.

## Three products

- **Factory** is the desktop app in this handbook: one person, their computer and their Git repositories.
- **Soda OS** is the operating system for a company's software factory: Soda Forge, persistent Projects, shared review and agents running on infrastructure the company controls. See the [Soda OS handbook](https://sodaos.dev/docs).
- **CanLang** is an optional language for business applications that factories can generate and maintain. See the [CanLang handbook](https://sodaos.dev/docs/canlang).

## Moving to a shared factory

The feed, requests, work, issues, pull requests and knowledge look and behave the same in Soda OS. A team that starts with Factory on one computer can move its projects to a Soda OS factory and keep working the way it already does.
