# Add a project

A project is one of your Git repositories opened in Factory. Each project has its own feed, requests, work and settings.

## Add a project

1. Open **All projects** in the sidebar, or press the **+** beside Projects.
2. Choose the account that can reach the repository.
3. Pick the repository from the list, or type its owner/name or repository URL and choose **Open repository**.

The project appears in the sidebar. Open it to reach its Feed.

## Project states

The Projects page shows each project's state:

| State | Meaning |
| --- | --- |
| Connected | Factory can read and write the repository and shows how many agents are working. |
| Needs you | Agents wait on an answer from you; the number counts the posts waiting. |
| Paused | Work is held; nothing new starts until you resume it. |
| Not set up | The repository is added but has no Factory request yet. |
| Sign in again | The account's sign-in expired. Saved drafts are kept; sign in again from Accounts. |

## Several projects

Factory keeps every project you add. The sidebar shows the open project with its pages and lists the others below it, each with its own count of posts waiting for you. Use **Jump to** (Ctrl K) to switch quickly.

## Disconnect a project

Disconnecting keeps the project and its history but stops Factory from reading or writing the repository. Factory stays disconnected until you reconnect.
