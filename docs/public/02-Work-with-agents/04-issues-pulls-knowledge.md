# Issues, pull requests and knowledge

These pages show the repository's own records next to Factory's view of them.

## Issues

**Issues** lists open and closed issues, a page at a time, with each issue's Factory state (waiting, building, or no Factory work). Open an issue to read and join the conversation, see its labels, and see the Factory facts: the role working on it and any pull request. You can create, edit, comment on and close issues here; drafts are kept on this computer until they are posted. Closing an issue does not stop Factory work on it; use Work detail for that.

## Pull requests

**Pull requests** lists the repository's pull requests with their review and check state. Open one to see its description, the review it received, its checks and the work item it belongs to.

## Knowledge

**Knowledge** holds what the project has learned: decisions and their reasons, findings and useful facts that agents and people recorded in the feed. Entries can be revised; the current version is shown and earlier versions stay in the record.

## Jump to

Press Ctrl K (⌘ K) to open **Jump to**. Type a project name, a page or a word from a post; use the arrow keys and Enter to open it, or Ctrl Enter to open it in a new window.
