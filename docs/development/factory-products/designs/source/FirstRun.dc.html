  3. 3

    Add a GitHub account

    Sign in to access your GitHub repositories. GitHub will ask for repository and profile access.

  4. 4

    Add your first project

    Pick a repository from your account, or open it by owner/name or repository URL. You can add more from Projects at any time.

Then you land on Projects

Your first project is listed there, with its feed one click away. Setup closes and does not come back unless you sign out of everything.
